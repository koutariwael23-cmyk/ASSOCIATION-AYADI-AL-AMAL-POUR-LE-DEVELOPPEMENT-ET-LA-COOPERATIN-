# Association Ayadi Al Amal pour le Développement et la Coopération

Site institutionnel trilingue (arabe, français, anglais) de جمعية أيادي الأمل للتنمية والتعاون, Beni Yakhlef, Mohammedia.

Site statique, sans dépendance : `index.html`, `assets/` (styles, scripts, textes `assets/i18n.js`), `img/`, `docs/`.

- Les textes des trois langues sont dans `assets/i18n.js`.
- Un texte entre `{{...}}` est une information encore manquante (surlignée en violet sur le site).
- Publication : GitHub Pages, branche `main`, dossier racine.
